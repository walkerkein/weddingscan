# WeddingSCAN 시험판

축의금 봉투 사진을 찍으면 AI가 번호·이름·금액을 읽어 장부로 만들어 주는 서비스(WeddingSCAN)의 **도우미 링크 시험 페이지**입니다. 운영: 스캔웍스.

- 시험 주소: https://walkerkein.github.io/weddingscan/helper/
- 시험 비밀번호: `1234` (화면 오른쪽 위 **설정**에서 바꿀 수 있음)

## 시험할 수 있는 것

1. 비밀번호와 찍는 사람 이름 입력
2. 촬영 세 가지: **화면에서 바로 찍기**(브라우저 안 카메라, 흐림 점수 표시), **카메라 앱으로 찍기**, **앨범에서 고르기**
3. AI 읽기: 소넷(`claude-sonnet-5-5`)이 먼저 모두 읽고, 애매한 봉투만 오퍼스(`claude-opus-5-5`)가 다시 읽음
4. 장부 보기(이름 찾기, 빠진 번호, 확인 필요 표시), 현금 합계 대조
5. 설정: 예식 날짜에만 열리는지 확인, 엑셀로 받기(두 모델의 1차·검토 값 포함), 장부 비우기, API 키 지우기

## API 키와 데이터

- 사진을 읽으려면 Claude API 키가 필요합니다. 처음 한 번 입력하면 **그 휴대폰 브라우저에만** 저장되고, 사진과 함께 Claude API로만 보내집니다.
- 장부와 설정도 그 휴대폰에만 저장됩니다. 서버나 이 저장소에는 아무것도 저장되지 않습니다.
- 시험용 키를 따로 만들고, 시험이 끝나면 설정에서 지우거나 Anthropic 콘솔에서 키를 없애 주세요.
- 이 방식은 본인 시험용입니다. 가족과 함께 쓰는 시험은 키를 서버에 두는 1단계 서버 버전에서 합니다.

## 파일

```
index.html          시험 안내
helper/index.html   도우미 화면
helper/app.js       화면 동작 (촬영, 흐림 점수, Claude 호출, 장부, 엑셀)
helper/logo.webp    SCAN 로고
```
